# 图文短篇流水线：从故事到可转发的单文件

> 目标：**一个故事 + N 张配图 + 一个能直接转发出去的页面**，全流程可重复，无人值守也能跑。

难点不在"生成一张图"，在**多张图风格一致**、**图文互相成立**、**成品是一个文件**。

---

## 一、四角色必须分开

创作和验收是两种相反的脑回路，混在一个环节里就会互相拖累：

| 角色 | 要什么 | 混在一起时的病 |
|---|---|---|
| **写** | 敢——放开写，多版并行 | 老想着"读者会不会觉得"→ 畏首畏尾 |
| **读** | 冷——只判断，不给面子 | 老想着"这里我想表达"→ 替作者辩护 |
| **画** | 冲——该给的光比敢给、该试的构图敢试 | 老想着"会不会有瑕疵"→ 手软 |
| **审** | 挑——放大看，只描述看见了什么 | 老想着"我本来想画的是"→ 自我说服 |

**操作规则**：
- 写的时候不读验收标准；读的时候不改稿，只给判断（"我读到这里不再关心了"），不给改法。
- 画的时候不想验收；审的时候不看 prompt，只看图。

**两个唯一判据**：
1. **作者想给的 = 读者收到的**（对不上 → 重写，不是改措辞）
2. **画师想画的 = 看图人看见的**（对不上 → 重画，不是改说明）

---

## 二、五步流程

```
① 定方向   两个"实质不同"的故事核（不是同一件事的两种说法）
② 写初稿   各写一版 → 冷读 → 挑一版 → 结构重写或局部精改
③ 定稿     连续两次冷读都过，才允许进入配图
④ 分镜与配图  按段落切镜 → 每镜一句画面描述 → 逐张生成 → 逐张核对
⑤ 交付     图片内嵌 → 单文件 HTML → 通读一遍 → 归档
```

### ② 里的"冷读"怎么做

冷读不是"再看一遍"，是**带着三个问题读**：

| 问题 | 不过的表现 |
|---|---|
| 我什么时候开始关心这个人/这件事？ | 读到一半还没关心 → 开头没建立"想要" |
| 我一直想知道的是什么？ | 读完没有任何悬念被吊着 → 没有"未知" |
| 他为此付出了什么代价？ | 什么也没失去 → 故事没有重量 |

三条有一个不过，回第 ② 步重写**结构**，不要在句子上打磨。

---

## 三、风格锚：多图一致的唯一办法

同一篇里的 N 张图必须像同一个人画的。做法是**固定一段"风格锚"文本**，拼进每一次生成：

```
风格锚（示例，按你的目标风格改写）：
同一画风：低饱和水彩，纸纹肌理，光源统一来自左上，
人物比例写实但面部简化，不出现文字与边框。
```

三条纪律：

1. **风格锚一字不改**——每次生成都用同一段，包括标点。
2. **只改"这一镜画什么"，不改画风**。
3. **同一批用同一模型、同一采样器、同一尺寸**。换模型 = 换画风。

---

## 四、分镜：一段文字对应一张图

| 原则 | 说明 |
|---|---|
| 一镜一事 | 一张图只讲一个动作或一个状态，别塞两个 |
| 可画性 | "他感到孤独"画不出来；"他一个人坐在亮着的便利店门口"可以 |
| 视角交替 | 连续三张同景别会闷；远—中—近交替 |
| 留白 | 关键情绪那一镜，画面信息要少 |

分镜表就三列：`镜号 / 画面描述（含风格锚）/ 对应正文段落`。

---

## 五、出图后的强制核对

每张图出来，**先看图再往下**，逐条过：

| 检查 | 不过怎么办 |
|---|---|
| 有没有硬伤（多手多指、文字乱码、结构错乱） | 重出 |
| 和上一张是不是同一画风 | 重出，并检查风格锚 |
| 画面是否真的对应这一段文字 | 改分镜，不是改文字 |
| 关键元素在不在（该有的道具/人物/环境） | 补进画面描述重出 |

**抽卡重出**：同一条 prompt 换种子重出 2–3 张，挑一张。**不要靠改 prompt 硬修**——那会把画风改掉。

---

## 六、交付：一个文件

图片 base64 内嵌进 HTML，得到**单个 .html**：双击能看、邮件能发、聊天工具能传，不会因为丢图变成红叉。

```bash
python story/story_to_html.py --manifest story.json --out story.html
```

`story.json` 的结构见脚本头部注释。

排版只要三件事：**正文可读（18px / 行高 1.9）、图片满宽、留白足够**。不要加动效。

---

## 七、常见失败

| 现象 | 根因 | 修法 |
|---|---|---|
| 图很好看，但和故事没关系 | 分镜直接从文字跳画面，没做"可画性"转换 | 每镜先写一句"这一镜要让人看见什么" |
| 前几张一个画风，后面跑偏 | 风格锚被临时改过，或换了模型 | 锁定风格锚 + 全批同模型 |
| 故事读起来"平" | 没有"想要"和"代价" | 回第 ② 步，不修句子 |
| 交付页图全裂 | 用了相对路径 | base64 内嵌 |
| 越改越差 | 在句子上反复打磨，结构没动 | 结构问题回源重写，局部问题才精改 |
